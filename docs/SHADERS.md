# Direct3D 12 shader tools

Build the Windows x64 tools using [the build guide](BUILD.md). Then use the commands below from the root of the installed preview. The shader probe uses the x64 `dxcompiler.dll` and `dxil.dll` from the same [Microsoft DXC release](https://github.com/microsoft/DirectXShaderCompiler/releases) or Windows SDK installation.

~~~powershell
$dxc = 'C:\Program Files (x86)\Windows Kits\10\bin\10.0.26100.0\x64'
.\bin\wsx_shader_probe.exe --caps
.\bin\wsx_shader_probe.exe --dxc-dir $dxc
.\bin\wsx_shader_probe.exe --dxc-dir $dxc --warp
.\bin\wsx_shader_probe.exe --dxc-dir $dxc --ray-query
.\bin\wsx_shader_probe.exe --dxc-dir $dxc --ray-query --warp
~~~

The probe checks Shader Model 6.6, the DXR tier, memory architecture and available wave lane counts. It compiles `cs_6_6` HLSL, dispatches the shader and compares GPU readback to the expected result. The ray query builds and clones a triangle BLAS, builds a TLAS with one transformed instance, and verifies an intersection and a miss. DXR requires tier 1.1 or higher. Exit code 77 means the adapter lacks a required feature. With Windows Graphics Tools installed, add `--debug` to fail on D3D12 debug layer errors.

## Inspect or translate a shader

Use Python 3.10 or newer to work with standalone shader files from your own test data or a build you are authorized to use. The tool identifies DXBC parts, DXIL headers and known Xbox markers, and extracts FSSM from the XDAT/XBCH layout it recognizes.

~~~powershell
python .\tools\prepare_shader.py inspect .\shader.dxbc
python .\tools\prepare_shader.py unpack .\shader.dxbc .\shader.fssm
python .\tools\prepare_shader.py lift .\shader.fssm .\lifted.hlsl --code-offset 0x10 --code-size 0x20
.\bin\wsx_shader_probe.exe --dxc-dir $dxc --compute .\lifted.hlsl --inputs 7 5 --expect 38 --dxil .\lifted.dxil
~~~

The offsets, lengths and expected result in this example refer to the synthetic fixture in the repository. For another shader, use its verified DWORD-aligned code range and expected output. A raw RDNA 2 instruction stream can also be passed to `lift` without a code range. The output file must be new.

The translator covers a straight line sequence of RDNA 2 scalar instructions. It handles general-purpose SGPRs, inline integers, literal DWORDs, 32-bit moves, comparisons, integer arithmetic, shifts, bitwise operations, and SCC-based selection. The probe starts with inputs in `s0` and `s1` and writes the selected SGPR from one compute thread. The translated code uses two constants at `b0` and an eight-byte result buffer at `u0`. It stops at the first unsupported instruction and prints its offset and word.

Vector and wave instructions, memory operations, control flow and Xbox shader resource binding remain outside this subset. The fixture verifies the translation on Windows. A console build is needed to validate the title's actual pipeline and guest ABI.

## Reproduce the regression run

When configuring CMake, add `-DWSX_DXC_DIR="<directory containing the matching x64 DXC DLLs>"` to register the shader tests. The test input is generated by [test_prepare_shader.py](../tools/test_prepare_shader.py). [shader_smoke.py](../tools/shader_smoke.py) verifies the full DXBC → XBCH → FSSM → HLSL → DXIL → GPU flow on a compatible adapter, with and without scalar carry. To create `shader.dxbc` for the commands above, run this from a source checkout.

~~~powershell
python -c "from pathlib import Path; import sys; sys.path.insert(0, 'tools'); from test_prepare_shader import xdat_shader; Path('shader.dxbc').write_bytes(xdat_shader())"
~~~
