# Can Leonida reach the GTA VI menu without the title executable?

Reviewed the public source at `91b36cf86cb92a95836eed8af73abc0671a61e31` on 22 November 2026. Leonida contains programs that can display game assets and exercise individual Xbox libraries without the title executable. Its documented game launch still starts from an executable supplied by the user. The authors report that GTA VI does not boot at this revision. [Project status](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/README.md#project-status)

## What actually starts

The build script compiles and copies `gta6rt.exe`. It then checks whether the expected title executable exists and reports its absence. The runtime requires an image argument. With `--dry-run` it maps that image and reports dependencies. With `--init` it also initializes loaded modules. With `--run` it calls the selected image's entry point. There is no path in this launcher from a folder of assets directly to a GTA menu. [Build stage](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/make_game.py#L609-L622) · [Runtime entry](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/runtime/src/main.cpp#L47-L103)

The change introducing `--run` included its own small C++ game fixture. CTest passes that compiled fixture to the loader with known arguments. It exercises startup, threads, files and exit. A passing test demonstrates execution of the supplied program. The fixture contains no GTA frontend. [Introducing commit](https://github.com/ItsNotRexed/Leonida/commit/0ca9bb8bc034ac2f5f322ce5b428af964bffca4e) · [Fixture](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/runtime/test/fixtures/tiny_game.cpp) · [CTest command](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/runtime/CMakeLists.txt#L365-L367)

## What works independently of the title entry point

| Path | Inputs and result |
| --- | --- |
| Map viewer | The browser viewer reads a local world manifest and GLB chunks. It can display generated terrain if those files are unavailable. A screenshot of a rendered scene alone cannot distinguish the source of the geometry or establish a game boot. [Viewer](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/viewer/index.html) · [Local server](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/viewer/serve.py) · [World builder history](https://github.com/ItsNotRexed/Leonida/commit/691527329c334f1c444e8f4c9b6dcfe9ff5b6e46) |
| Movie decoder | A Windows test feeds a movie to the package's Bink DLL. The upstream notes describe decoded frames and explicitly document a successful skip when its input is absent. A frame can therefore be reproduced independently of the title's startup logic. [Decoder test and required inputs](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/runtime/test/bink_decode_test.md) |
| UI data and scripts | The RBF0 tool reads UI resources and writes structured trees. The authors report 136 screen definitions, 65 movie-view definitions and 61 flow-block resources in the studied package. Their notes leave field semantics and archive paths unresolved. The PSIN records identified in the script archive are metadata. I found no documented execution path from these records to the original main menu in this revision. [Tree decoder](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/tools/rbf0_tree.py) · [Screen counts and decoder limits](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/docs/rbf0.md) · [PSIN findings](https://github.com/ItsNotRexed/Leonida/blob/91b36cf86cb92a95836eed8af73abc0671a61e31/docs/psin.md) |

A Discord screenshot can record the pixels a viewer saw. To attribute them to the original interactive menu, the missing evidence is the program and command that produced them, which original resources supplied the first screen, and what happened when an option was activated. This audit inspected public source and commit history. It did not reproduce the author's Discord session or run the upstream test suite.

## Reuse in AnyXboxSeries

Leonida identifies its own code as GPLv3 or later. Attribution alone does not relicense it under AnyXboxSeries' CPAL terms. The `rpf9-explorer` submodule has separate terms and Leonida documents the absence of a licence file there. This note uses independently described format observations and links to source. It includes no upstream implementation or game data.
